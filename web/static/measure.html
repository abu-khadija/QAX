How we measure — every number, its truth, and the command that repeats it

A percentage without a method is a slogan. Below is everything QAX claims, what each number counts, who decided the right answer before QAX ran, how many cases it covers, and how you re-run it on your own machine.

Last measured 21 October 2026 · QAX branch feat/functional-qa-track · one machine (macOS, Chromium).

Truth comes firstEvery expected outcome is written before the run — by a person, an upstream maintainer, or an independent author. QAX never grades itself.
Did-not-run is not a passA step or check that could not run is ERROR or SKIP, and counts against the score — never as a pass.
No AI decidesPass, fail, "vulnerable" and "reproduced" come from deterministic checks. AI may write cases; its cases are judged by the same code.
Numbers carry their nEach result says how many apps and cases it covers. None is a general rate for every app.

What we do not claim yet

  • AI-written test cases are not measured yet. The harness exists (make eval-generation); it has not run against a live model.
  • No general accuracy rate. The numbers above hold for these apps, these cases and this machine — n is stated on each.
  • Jira and Xray end to end (story in, results and bugs out) have not been exercised against a live instance for functional runs.
  • No comparison with another tool or with a person yet. A fair baseline (same apps, same stories, same time box) is planned, not done.
  • "Time saved", "AI confidence", "quality score" — we show none: there is no honest way to measure them yet.
