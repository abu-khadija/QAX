# strategy/ — what each file is

| Folder | What is in it |
|---|---|
| [evidence/](evidence/) | Measured results: real-app case studies (DRF, Go/Gin, Gitea), reality-check results, the orchestrator fix evidence, the generic-agent comparison, the dependency audit |
| [intel/](intel/) | Competitive study (Qodo) and the pitch material |
| [legal/](legal/) | IP checklist and the cleanup inventory, for counsel |
| [archive/](archive/) | Superseded plans and assessments, kept as history (old roadmap up to 2026-10-16, early verdict/state/architecture, refactor plan) |

Rule: a new plan supersedes an old one by moving the old one to `archive/`, never by deleting it.
